# AI Workflow Orchestrator – Quality Control

This repository contains a Proof of Concept (POC) for an AI-driven workflow
orchestrator that automates quality control escalation and root-cause resolution.

## Key Capabilities
- Event-driven workflow orchestration
- LLM-based root cause analysis
- Human-in-the-loop approvals
- Incident report generation
- Full observability into AI reasoning

## Tech Stack
- Python
- FastAPI
- LangChain (LLM reasoning)
- Docker
